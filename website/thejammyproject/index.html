Self-Hosted Cloud Platform

Designed, built and operate a self-hosted cloud platform focused on automation, security and platform engineering principles.

Key Features

  • Built and operate a three-node RKE2 Kubernetes cluster alongside a dedicated KVM/libvirt virtualisation platform.
  • Developed self-service provisioning for virtual machines, encrypted block storage, backups, snapshots and isolated tenant networks.
  • Implemented managed WireGuard VPNs, subnetting, NAT gateways, security groups and public/private network routing.
  • Automated infrastructure provisioning and configuration management using Terraform, Ansible and cloud-init.
  • Implemented GitOps deployment workflows using Argo CD and GitHub Actions, including automated reconciliation and self-healing.
  • Deployed a three-instance PostgreSQL 18 cluster using CloudNativePG, with streaming replication, enforced TLS, encrypted Longhorn volumes and tested automatic failover.
  • Implemented encrypted PostgreSQL base backups, continuous WAL archiving and tested point-in-time recovery using a local S3-compatible object store.
  • Built a three-node HashiCorp Vault Raft cluster providing highly available secrets management, dynamic PostgreSQL credentials and PKI services.
  • Implemented short-lived mTLS certificates and automated certificate rotation for internal service-to-service communication.
  • Protected customer compute storage using LUKS2 encryption with encryption keys wrapped through Vault Transit.
  • Applied Kubernetes security controls including default-deny NetworkPolicies, least-privilege RBAC, non-root containers, seccomp profiles and read-only root filesystems.
  • Implemented monitoring and alerting using Prometheus, Grafana and Alertmanager, with centralised logging through OpenSearch.
  • Integrated Trivy, Gitleaks, Semgrep, Checkov and Bandit security scanning, with vulnerability findings consolidated in DefectDojo.
  • Implemented keyless container-image signing using Cosign and Sigstore, immutable digest pinning and Kyverno admission enforcement for first-party images.
  • Deployed a three-node NATS JetStream cluster with encrypted persistent storage and three-replica event streams.
  • Designed service and tenant isolation using dedicated PostgreSQL roles, Vault-issued dynamic credentials and PostgreSQL row-level security.
